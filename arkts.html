ArkTs - 鸿蒙应用开发语言

ArkTs 是华为为 HarmonyOS 打造的主力应用开发语言，基于 TypeScript 扩展，提供声明式 UI 开发范式。

核心优势

📱 声明式 UI

采用 ArkUI 声明式开发范式，高效构建跨设备自适应界面

🔄 跨端协同

一套代码适配手机、平板、穿戴、车机等多种终端设备

⚙️ 方舟编译器

通过 ArkCompiler 实现 AOT 编译，显著提升应用运行性能

开发生态

DevEco Studio · 鸿蒙 SDK · 应用市场 · 开发者社区 · 技术认证

ArkUI 框架

ArkUI 是 HarmonyOS 提供的声明式 UI 开发框架，支持丰富的组件和灵活的布局方式。

布局方式

📐 线性布局 Column/Row

Column() { Text('Hello') }.width('100%').height('100%')

纵向/横向排列子组件，最基础的布局方式

🔲 弹性布局 Flex

支持自动换行、对齐方式、空间分配等高级布局控制

📊 栅格布局 GridRow

基于断点的响应式栅格系统，适配不同屏幕尺寸

状态管理

@State · @Prop · @Link · @Provide · @Consume · @Observed

组件开发

ArkUI 提供丰富的系统组件，同时支持开发者自定义组件。

常用组件

📝 Text 文本

Text('Hello ArkTs').fontSize(24).fontColor('#00f5ff')

文本显示组件，支持富文本、截断、对齐等属性

🖼️ Image 图片

Image($r('app.media.logo')).width(100).height(100)

图片显示组件，支持本地/网络图片加载

📋 List 列表

List() { ForEach(dataArray, item => ListItem() { Text(item) }) }

高性能列表组件，支持懒加载与滑动操作

🧭 Tabs 页签

多页签导航组件，支持顶部/底部切换与自定义页签栏

跨端适配

HarmonyOS 的多设备协同能力，让应用一次开发、多端部署。

适配策略

📱 响应式布局

使用媒体查询和断点系统，自动适配不同屏幕尺寸

🔄 多端迁移

支持应用状态在设备间无缝迁移，延续用户体验

🖥️ 自适应组件

Navigation、SideBarContainer 等组件自动适配手机/平板/PC

目标设备

智能手机 · 平板电脑 · 智能穿戴 · 智慧屏 · 车机系统

方舟编译器

ArkCompiler 是华为自研的应用编译器，为 ArkTs 提供高效的编译执行能力。

编译特性

⚡ AOT 编译

应用安装时直接编译为机器码，运行时无需解释执行，启动速度提升 60%

🧹 无 GC 运行

采用引用计数内存管理，消除垃圾回收带来的卡顿

🔧 多语言编译

支持 ArkTs、JS、C/C++ 统一编译，跨语言高效调用

性能数据

应用启动提升 60% · 滑动流畅度提升 50% · 内存占用降低 30%
